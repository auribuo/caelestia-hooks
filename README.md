# caelestia-hooks

Simple way to run shell hooks on Caelestia theme changes

## Installation
 
`go install github.com/auribuo/caelestia-hooks@latest`

Ensure `go env GOBIN` is on your `PATH`

## Usage 

Autostart `caelestia-hooks` on startup or manually 

Place shellscripts in `~/.config/caelestia/hooks`
